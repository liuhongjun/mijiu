# 米酒酿造工厂 AI 管理体系 · 文档总览

本项目给出一套**可落地的、覆盖全厂业务**的 AI 管理体系：从原料进厂、发酵酿造、质量食安，到销售渠道、财务、法务、人力资源与客户服务。

## 适用对象

以**通用中型米酒厂**为基线（年产 3000 吨、120 人、金蝶/用友 ERP 为主、无 MES/LIMS）。参数与基线见 [00-config.md](00-config.md)。实际规模不同时，只需替换 00-config 第 1、3 节的参数，其余结论仍然适用。

## 配套工程文件

| 路径 | 内容 | 用法 |
|---|---|---|
| `agents/` | 提示词契约、工具契约、审计日志 Schema、验收测试框架 | 见 [agents/README.md](agents/README.md) |
| `tools/estimate-model.xlsx` | 投资测算表（参数 / 投资明细 / 收益测算 / 说明 四表，公式驱动） | 直接打开，改"参数"表浅蓝格即重算 |
| `tools/build-estimate-model.mjs` | 测算表生成器（纯 Node 标准库手写 OOXML，无第三方依赖），生成后自校验 ZIP 与 XML | `node tools/build-estimate-model.mjs` |
| `tools/audit-docs.mjs` | 文档一致性审计：302 条交叉链接可解析性、Agent 登记一致性、红线语义、emoji 检查 | `node tools/audit-docs.mjs` |

## 质量校验

全套文档已通过自动审计（最近一次运行结果）：**302 条交叉链接全部可解析、0 断链**；05–11 七个业务域分册**各 9/9 节结构齐备**，引用到的 Agent ID **全部在 03 分册登记**（无越权新增）；七项红线（不得改工艺参数、不得替代法定记录人签字、禁止对外发布、含理性饮酒提示、不面向未成年人、AI 无付款与过账权限、不出法律意见、不作人事决定）**逐条语义到位**；全套无 emoji。

估算表校验：ZIP 签名与 9 个部件结构正确、4 张工作表与 45 个公式写入成功、XML 全部合法。**说明**：本机沙箱禁止调用 Excel COM，因此未能做"用 Excel 实际打开"的端到端验证；首次打开请确认无修复提示。
